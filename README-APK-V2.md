# Burma AI Studio APK v2

This branch is exclusively for the Android APK and must never be merged into the production website branch.

## Version 2.0.1

- The application interface is bundled from `apk-web` into the Android package.
- Capacitor does not use `server.url`.
- The APK does not open a Vercel preview deployment and does not require Vercel authentication.
- Desktop, phone and tablet website production remains on `main` and is not modified by APK builds.

Build output: `Burma-AI-Studio-v2.0.1.apk`
